Third-party plugin sample

Markdown Table Formatter

Normalize a simple pipe table in this window. Your input stays here and is never saved.

Input table

Use one header row, one separator row, and optional data rows. Put an unescaped pipe at each row edge.

Waiting for input

Column alignment

Choose an alignment for each column. The default keeps Markdown default alignment.

Formatted output

The tool formats table structure. It does not render Markdown or interpret cell contents.

You can select the result and press Ctrl+C at any time.

Processing stays in this isolated plugin window. The plugin does not save input, call a network service, or log cell contents.
